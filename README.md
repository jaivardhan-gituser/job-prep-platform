# Job Preparation & Application Platform

An end-to-end platform bridging offline job applications, company interview intelligence, live job scraping, ATS resume targeting, and AI-driven streaming mock interviews.

## System Modules
1. **Offline Application Hub**
2. **Company Intelligence Engine**
3. **Live Job & Internship Aggregator**
4. **AI Resume Analyzer & Targeter**
5. **AI Mock Interview & Evaluation System**

## Tech Stack
* **Backend:** Python 3.11+, FastAPI, Async SQLAlchemy, PostgreSQL, Alembic
* **Frontend:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS
* **Task Queue & Scrapers:** Celery, Redis, Playwright, BeautifulSoup4
* **AI Pipeline:** OpenAI API / Google Gemini SDK, Server-Sent Events (SSE)
